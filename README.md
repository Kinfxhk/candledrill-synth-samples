# CandleDrill synth samples

**Synthetic practice OHLCV for [CandleDrill](https://github.com/Kinfxhk/candledrill)** (K線操練場).

> **Not market data.** These bars are generated by a seeded model with a Globex-like session calendar and a hand-tuned intraday volume shape. They are **not** CME data, **not** NQ futures quotes, and **not** a replay of any data vendor. Do not use them for live trading, research claims about real markets, or as a substitute for licensed market data.

License: **MIT** (code + synthetic samples).

## What’s included

| Path | Description |
|------|-------------|
| `SYNTH-NQ-GLOBEX_1min.csv` | ~90 calendar days of 1-minute synthetic bars (~88k rows, ~5 MB) |
| `SYNTH-NQ-GLOBEX_meta.json` / `_summary.json` | Generator meta + shape summary |
| `samples/SYNTH-NQ-GLOBEX_14d_1min.csv` | Short 14-day pack for quick import |
| `params-hand-tuned.json` | Public regenerative defaults (seed, calendar, activity curve) |
| `tools/gen_synth_nq_globex.py` | Regenerator (Python 3 stdlib only) |

## Import into CandleDrill

1. Open CandleDrill → **Import CSV**
2. Pick `SYNTH-NQ-GLOBEX_1min.csv` (or the 14-day sample)
3. **Symbol:** use something like `PRACTICE-NQ-GLOBEX` — CandleDrill reserves the `SYNTH-` prefix for its built-in generator API
4. **tickSize:** `0.25`
5. **UTC offset:** `-300` (fixed EST; no DST in this pack)
6. Mapping: `datetime, open, high, low, close, volume`

## Regenerate

```bash
python3 tools/gen_synth_nq_globex.py \
  --params params-hand-tuned.json \
  --out-csv SYNTH-NQ-GLOBEX_1min.csv \
  --out-meta SYNTH-NQ-GLOBEX_meta.json \
  --out-summary SYNTH-NQ-GLOBEX_summary.json
```

Same seed + same params → identical CSV.

## Design notes

- Tick size 0.25; closes on grid
- Near-24h Globex-like windows (Sun–Thu 18:00→17:00 exchange-local); **hour 17 has no bars** (maintenance)
- RTH-ish open/close volume peaks; thin overnight ETH
- Independent start price level (`18000`) and fake calendar from `2026-01-05`
- Fixed offset −05:00 (no DST) — documented limitation
