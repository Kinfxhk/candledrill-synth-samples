## What’s included

| Path | Description |
|------|-------------|
| `SYNTH-TECHIDX-24H_1min.csv` | ~90 calendar days of 1-minute synthetic bars (~88k rows, ~5 MB) |
| `SYNTH-TECHIDX-24H_meta.json` / `_summary.json` | Generator meta + shape summary |
| `samples/SYNTH-TECHIDX-24H_14d_1min.csv` | Short 14-day pack for quick import |
| `params-hand-tuned.json` | Public regenerative defaults (seed, calendar, activity curve) |
| `tools/gen_synth_techidx_24h.py` | Regenerator (Python 3 stdlib only) |

Public pack id: `SYNTH-TECHIDX-24H`.

## Import into CandleDrill

1. Open CandleDrill → **Import CSV**
2. Pick `SYNTH-TECHIDX-24H_1min.csv` (or the 14-day sample)
3. **Symbol:** `PRACTICE-TECHIDX-24H` — CandleDrill reserves the `SYNTH-` prefix for its built-in generator API
4. **tickSize:** `0.25`
5. **UTC offset:** `-300` (fixed EST; no DST in this pack)
6. Mapping: `datetime, open, high, low, close, volume`

## Regenerate

```bash
python3 tools/gen_synth_techidx_24h.py \
  --params params-hand-tuned.json \
  --out-csv SYNTH-TECHIDX-24H_1min.csv \
  --out-meta SYNTH-TECHIDX-24H_meta.json \
  --out-summary SYNTH-TECHIDX-24H_summary.json
```

Same seed + same params → identical CSV. A retired id in `symbol` is rewritten to the current public id before metadata is written.

```bash
python3 tools/check_public_surface.py
```

## Design notes

- Tick size 0.25; closes on grid
- Near-24h session-like windows (Sun–Thu 18:00→17:00 local); **hour 17 has no bars** (maintenance)
- Open and close volume peaks; thin overnight hours
- Independent start price level (`18000`) and an invented calendar from `2026-01-05`
- Fixed offset −05:00 (no DST) — documented limitation
